# Store listing draft

## Short English description
Fold long user messages and copy user or AI responses in AI Studio Build chats.

## Short Arabic description
اطوِ رسائل المستخدم الطويلة وانسخ رسائل المستخدم وردود الذكاء الاصطناعي في شات Build.

## Long description
AI Studio Fold & Copy is an independent privacy-first helper for Build chats. It changes only the presentation of long user messages and adds accessible copy controls. It does not collect, send, or store conversation content and makes no network requests.

## Permission justification
`storage` is used only for user preferences in `chrome.storage.sync`. No other permissions are required.
