# AI Studio Fold & Copy

إضافة Chrome مستقلة تعمل على **شات Build فقط** في Google AI Studio داخل `aistudio.google.com/apps/*`.

> الإضافة غير تابعة لجوجل أو Gemini أو Google AI Studio.

## المميزات

- طي رسائل المستخدم الطويلة فقط بعد قياس الارتفاع الحقيقي.
- تلاشي ناعم وزر حقيقي يدعم لوحة المفاتيح وARIA.
- نسخ رسالة المستخدم كاملة ورد الذكاء الاصطناعي بصيغة Markdown.
- استثناء عناصر الواجهة وThoughts افتراضيًا.
- فشل آمن عند تغير DOM؛ العنصر غير المؤكد لا يتم تعديله.
- بلا شبكة أو تحليلات أو كود بعيد أو تخزين لمحتوى المحادثات.

## التثبيت اليدوي

1. حمّل أو انسخ المجلد.
2. افتح `chrome://extensions`.
3. فعّل **وضع المطور**.
4. اختر **Load unpacked** وحدد مجلد الإضافة.
5. افتح صفحة Build على `https://aistudio.google.com/apps/`.

## الخصوصية

راجع [PRIVACY.md](PRIVACY.md). الصلاحية الوحيدة هي `storage` لحفظ الإعدادات في `chrome.storage.sync`.

## تنبيه التوافق

قد تغير AI Studio بنية DOM مستقبلًا. عند حدوث كسر، أرسل لقطة شاشة منزوعة الخصوصية؛ المحددات موجودة مركزيًا في `src/content/selectors.js`.

## التنقل السريع بين الرسائل

تظهر على يمين الشات خريطة مصغرة بشرائط بعدد رسائل المستخدم. مرّر المؤشر على أي شريط لرؤية معاينة، واضغط عليه للانتقال بسلاسة إلى الرسالة نفسها. لا يتم تغيير موضع التمرير تلقائيًا؛ الانتقال يحدث فقط عند ضغط المستخدم.
